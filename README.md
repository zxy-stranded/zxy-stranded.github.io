# 观己 · 自我探索工具站

一个兼容手机和电脑的 H5 工具站，把历史人物、日常选择、诗词与传统文化变成轻松的探索体验。无需注册登录，从首页选择感兴趣的功能即可进入对应页面。

## 页面与功能

首页用六张同规格卡片提供功能入口，点击整张卡片即可进入。上方用六张书卷插画海报推荐功能，每 3 秒以滑动过渡切换；鼠标悬停圆点即可切换并暂停，移开后继续，也支持点击和键盘选择。桌面端右侧搭配“今日小问”，每天一个自我探索问题，可进入“六十四种反思”继续探索；手机端上下排列。子页面右上角统一通过“返回全部”回到首页。

| 功能         | 可以用来做什么                                   | 页面路径            |
| ------------ | ------------------------------------------------ | ------------------- |
| 人物画像测试 | 通过日常情境选择，找到与你处事方式相近的历史人物 | `/apps/portrait/`   |
| 双人契合度   | 邀请朋友一起作答，了解彼此相近与不同的选择倾向   | `/apps/pair/`       |
| 判词猜人     | 每天猜一位历史人物，在轻量答题中认识人物故事     | `/apps/daily/`      |
| 人物关系图谱 | 探索历史人物的同类原型、合作关系与分歧           | `/apps/network/`    |
| 诗意起名     | 从字义、读音和诗词出处中挑选喜欢的名字           | `/apps/names/`      |
| 六十四种反思 | 借助传统卦象，为当下的问题寻找新的思考角度       | `/apps/reflection/` |

## 人物画像测试

想知道自己的选择方式更像哪位历史人物，可以从这里开始。

- 选择 **15 题极速版**或 **30 题完整版**，回答贴近日常生活的情境问题。选中选项后自动进入下一题，也能返回上一题修改答案。
- 从 **50 位历史人物、10 组原型**中匹配主画像和次要画像。每个人物都有独立的性格参数、标签和解读。
- 结果包含八维对比、与你接近的侧面、差异所在及逐题吻合说明，帮助理解“为什么像”。
- 可查看人物档案与图鉴，保存分享图或复制邀请链接。微信内优先长按图片保存；结果地址可在其他浏览器恢复本次测试。答题进度可在当前浏览器暂存，回来继续。

## 双人契合度

适合和朋友、伴侣或合作伙伴一起探索，用一份报告打开沟通话题。

- 发起者完成 **30 题完整版**后生成邀请链接，对方打开链接并完成同样的测试。
- 展示两人在 **8 个维度**中有几个接近、各维度的对照，以及可以互补和需要提前沟通的侧面。
- 从 **18 组历史关系原型**中选择一种叙事参照，帮助理解不同的相处节奏。
- 被邀请者同时获得自己的单人画像，并可继续邀请其他朋友。

## 判词猜人

适合每天花一点时间读一句判词、认识一位故人。

- 每天北京时间 **0 点**更新一道四选一题，线索来自人物判词或反差细节。
- 答错后获得提示并可继续选择；答对后展示人物卡片，支持查看完整档案。
- 记录连续答对天数，每连续完成 **3 天**解锁一张收藏版人物卡，最多 **10 张**。看提示后答对也计入记录。
- 收藏版属于额外奖励，不影响主测试对全部 50 位人物的匹配。

## 人物关系图谱

适合从人物之间的连接了解历史，也可以接着自己的测试结果继续探索。

- 默认展示 **50 位人物**，通过搜索或点击节点选择感兴趣的人物。
- 区分同类原型、合作交往、对立分歧与跨时代参照，可筛选关系、缩放或拖动画布。
- 选中人物后展示判词、原型标签及相连人物列表，每条人工关系附简短解读与资料线索。
- 支持进入人物详情，或切换查看补充关系人物。跨时代参照有明确标注，不表示真实相识。

## 诗意起名

适合为宝宝起名或寻找名字灵感，反复浏览、比较，再慢慢决定。

- 填写使用的姓氏，选择用字偏好及古风、现代、中性、《诗经》或《楚辞》等风格；可选填母亲姓氏并融入名字。
- 每批生成 **10 个候选名**，展示读音、字义、用字文化五行标注和音韵提示。有诗词出处的候选会展示原句、篇名与作者。
- 点击“换一批”继续探索，喜欢的名字可收藏，方便之后比较。生僻姓或家族特殊读音支持手动填写。
- 可选填出生日期与时间，查看简易干支五行计数，作为传统文化参考。当前收录 **671 个用字、240 条诗句、179 个姓氏**。

## 六十四种反思

适合在面对一个问题时，借一组提示整理想法、尝试不同视角。

- 可选填一个正在思考的问题，使用 **三钱六掷**或**按时间取象**两种方式生成卦象。
- 展示卦名、六爻、动爻与变卦，说明本次使用的取象规则。
- **64 卦各有独立解读**，包括一句核心提示、三个反思问题和一个行动建议。
- 解读供文化探索与自我反思，不构成决策依据。

## 使用与保存

手机和电脑均可使用，界面会随屏幕宽度调整。交互功能需要浏览器正常启用 JavaScript。

答题进度、每日记录和主动收藏的名字保存在当前浏览器；更换设备或清理浏览器数据后不会自动同步。起名输入的姓氏与出生时间不持久保存。结果页地址包含本次答案的恢复信息，换浏览器时请保留完整地址，只供自己留存或发给信任的人；公开邀请朋友测试请使用“复制邀请链接”。双人邀请链接会携带主动分享的八维摘要，请发给愿意分享的人。

人物画像是趣味性格解读，不是专业心理测评；起名与卦象内容供文化娱乐和自我反思参考。
