资料与依赖说明

人物叙事、现代反思文案及字义简释为本项目编辑内容，数值与元素分类为文化解读，不是科学或历史定论。

诗词原文选自公有领域古籍，电子文本整理来源为 chinese-poetry/chinese-poetry；保留来源整理项目许可。本项目作繁简转换、筛选和取字，并保留原句及出处。未逐条校勘版本异文。

历法使用 lunar-javascript；拼音使用 pinyin-pro，数据标注中的多音字与姓氏仍建议家庭核对。时间取象只是已声明的数法，不代表唯一传统口径。

开源组件许可：

  • Vue / Vue Router
  • qrcode
  • lunar-javascript / pinyin-pro
  • d3-force / d3-dispatch / d3-quadtree / d3-timer
